Generator promptu AI

Ustaw parametry, skopiuj gotowe polecenie i wklej je do dowolnego modelu językowego — Claude, ChatGPT, Gemini lub innego. Prompt sam tłumaczy modelowi strukturę pliku JSON, więc nie musisz dołączać żadnej dokumentacji. Otrzymaną odpowiedź wgrywasz w zakładce Import AI.

Wpisz temat materiału — dopóki pole jest puste, prompt zawiera miejsce do uzupełnienia ręcznego.

Prompt trafia do stdin, a ścieżkę do materiału podajesz w treści polecenia.

# zapisz prompt przyciskiem „Pobierz .txt”, a następnie:
claude -p "$(cat prompt.txt)

# szybka kontrola składni
python3 -m json.tool pakiet.json > /dev/null && echo "JSON poprawny"

Przy obszernym skrypcie poproś najpierw o spis rozdziałów, a potem generuj pakiety rozdział po rozdziale. Jeden zestaw na 300 fiszek jest trudniejszy w nauce niż pięć tematycznych.

  1. Załóż nową rozmowę, żeby wcześniejszy kontekst nie zniekształcił odpowiedzi.
  2. Dołącz materiał (PDF lub zdjęcia notatek) jako załącznik.
  3. Wklej prompt i wyślij.
  4. Skopiuj całą odpowiedź — łącznie z blokiem ```json, import sam go usunie.

Jeżeli odpowiedź się urwie, napisz „kontynuuj od ostatniego kompletnego obiektu” i sklej fragmenty, albo poproś o mniejszą liczbę fiszek.

  1. Wybierz model rozumujący (na przykład tryb „Thinking”) — daje wyraźnie mniej błędów merytorycznych.
  2. Dołącz PDF przyciskiem spinacza, poczekaj, aż plik się wczyta.
  3. Wklej prompt i wyślij.
  4. Skopiuj odpowiedź do pliku .json albo wklej ją wprost w zakładce Import AI.

Gdy model uparcie dopisuje komentarz przed JSON-em, dopisz na końcu promptu: „Twoja odpowiedź musi zaczynać się znakiem { i kończyć znakiem }”. Import i tak poradzi sobie z otoczką, ale czysta odpowiedź łatwiej przechodzi walidację.

  1. W Google AI Studio ustaw Temperature na 0,2–0,4 — ogranicza to improwizację.
  2. Jeżeli dostępna jest opcja Structured output / JSON mode, włącz ją.
  3. Dołącz materiał i wklej prompt.
  4. Skopiuj wynik do pliku albo wprost do zakładki Import AI.

Gemini bywa hojny w liczbie fiszek. Jeżeli przekroczy zamówioną liczbę, nie szkodzi — nadmiar usuniesz w edytorze przed zapisem zestawu.

Prompt nie zawiera niczego specyficznego dla jednego dostawcy, więc zadziała także w modelach lokalnych.

  • Model musi mieć okno kontekstu mieszczące prompt (około tokenów) oraz Twój materiał.
  • Ustaw niską temperaturę — przy materiale medycznym kreatywność jest wadą.
  • Mniejsze modele lepiej radzą sobie z partiami po 10–15 fiszek niż z jednym dużym zamówieniem.
  • Jeżeli model nie utrzymuje poprawnej składni JSON, zmniejsz liczbę fiszek i sklej kilka pakietów w edytorze.

Co dalej z odpowiedzią modelu

  1. 1 Przejdź do zakładki Import AI i wgraj plik albo wklej treść odpowiedzi.
  2. 2 Sprawdź raport walidacji — zobaczysz liczbę rozpoznanych fiszek i listę elementów pominiętych wraz z powodem.
  3. 3 Zawsze przejrzyj treść przed nauką. Model potrafi zmyślać mimo rygoru w prompcie — przycisk „Otwórz w edytorze i popraw” pozwala poprawić wszystko przed zapisem.
Zastrzeżenie: żaden prompt nie gwarantuje bezbłędności modelu. Materiał wygenerowany automatycznie traktuj jak notatki kolegi z roku — pomocne, ale wymagające sprawdzenia w podręczniku, zanim oprzesz na nich decyzję kliniczną.
