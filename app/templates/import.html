Jak przygotować pakiet

Najprościej skorzystać z generatora promptu, który złoży gotowe polecenie dla wybranego modelu. Pełna specyfikacja formatu znajduje się w pliku AI_SCHEMA.md. Poniżej skrócony schemat. 

{
  "title": "Tytuł zestawu",
  "description": "Opis zestawu",
  "subject": "Przedmiot",
  "tags": ["Tag pierwszy", "Tag drugi"],
  "visibility": "private",
  "cards": [
    { "front": "Pojęcie", "back": "Definicja", "hint": "opcjonalnie", "note": "opcjonalnie" }
  ],
  "questions": [
    {
      "prompt": "Treść pytania",
      "explanation": "Uzasadnienie",
      "options": [
        { "text": "Wariant A", "is_correct": true,  "feedback": "opcjonalnie" },
        { "text": "Wariant B", "is_correct": false, "feedback": "opcjonalnie" }
      ]
    }
  ]
}
